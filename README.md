# data-report-html

单文件交互式 HTML 数据报告：CSS 设计系统 + ECharts 模板 + 组件库（KPI 卡、漏斗、洞察卡、术语表、路线图）+ 交付前自检。

## 安装

```bash
git clone https://github.com/imQiwei/data-report-html.git ~/.claude/skills/data-report-html
```

Claude Code 会按 `SKILL.md` 里的 `description` 自动匹配触发，也可以用 `/data-report-html` 手动调用。完整说明见 [SKILL.md](SKILL.md)。

`references/design-system.md` 是叙事型报告（多 Tab 递进、预测折线、路线图）的组件和 UI 坑点。

skill 用中文编写。示例数字均为虚构，表名、字段名为通用占位，请按自己的数据平台替换。
